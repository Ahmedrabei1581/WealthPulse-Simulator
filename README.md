🚀 WealthPulse-Simulator | Enterprise Banking & Wealth Management Analytics Platform
"Where rigorous banking operations meet data science and financial intelligence."

A professional, enterprise-grade bilingual (English/Arabic) web application designed for financial simulations, wealth management, and structured banking products. Developed specifically to meet the high standards of financial institutions, corporate banking environments, and official institutional websites.

✨ Key Financial Modules
The system features 4 core financial calculation engines built with rigorous accounting standards:

📊 Daily Compounding Return (%):

Computes daily compound growth on capital principal.

Calculates the Effective Annual Rate (EAR) and compares it against simple nominal rates.

💵 Fixed Daily Amount Simulation:

Manages fixed daily cash flows and tracks total balance growth over time.

🏦 Time Of Deposit (Periodic Payout):

Supports flexible payout frequencies (Monthly, Semi-Annual, Annual) with precise yield structuring.

📜 Certificate Of Deposit (3 Years):

Manages 3-year investment certificates with multiple payout frequencies (Monthly, Quarterly, Semi-Annual, Annual).

🛠️ Technical Stack
Built using modern Python libraries and data science tools tailored for financial analytics:

Core: Python 3.14+

Web Framework: Streamlit (Responsive Corporate Interface)

Data Engineering & Analysis: Pandas, NumPy

Data Visualization: Matplotlib (Interactive Financial Growth Charts)

Report Generation:

ReportLab: Generates official PDF certificates with robust handling of font rendering and layout directions.

OpenPyXL: Exports styled, executive Excel reports equipped with formatted tables and summaries.

🌐 Engineering & UI Highlights
Full Bilingual Support: Seamless switching between English (Default) and Arabic via an interactive sidebar.

Bidi-Text & RTL Handling: Advanced HTML/CSS embedding ensuring numerical values, percentages, and currencies render flawlessly without visual overlap in both language modes.

Instant Exporting: One-click generation and download of professional executive reports in Excel and PDF formats.

⚙️ Quick Start
To run this project locally on your machine, follow these steps:

Clone the repository:

Bash
git clone https://github.com/Ahmedrabei1581/WealthPulse-Simulator.git
cd WealthPulse-Simulator
Install dependencies:

Bash
pip install -r requirements.txt
Run the Streamlit application:

Bash
streamlit run Daily_interest_APP.py
